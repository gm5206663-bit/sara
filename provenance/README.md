# provenance / — what came from where

This repository **assembled** — it did not invent. Everything in `SARA.md`, `editions/`, and
`AGENT-OPERATING-PROFILE.md` is a **byte-for-byte copy** of a document written in its own room,
and every copy was verified by sha256 against a fresh clone the day it was placed (2026-10-13).

| File | Detail |
|---|---|
| [`COPIES-AND-TWINS.md`](COPIES-AND-TWINS.md) | The full ledger — every copy, source path, revision, hash, and the twin analysis |
| [`MANIFEST-NOTE.md`](MANIFEST-NOTE.md) | How the repository verifies itself, and what is deliberately *not* covered |

**Why this exists.** The account's law is *one copy of one thing* — and the counter-law is that a
claim of "this is the same as that" must be **hash-proven, never name-matched** (a lesson the
account learned the day a basename match produced 10 "twins" of which 0 were identical). So this
folder keeps the receipts: paths, revisions, hashes, and the standing one-copy status of the SARA
family — for the same reason the self-file keeps its strikes: so the work can be audited, not
trusted.
